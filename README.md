# AI-Board-Soldering-Checker
Using  open source data base for checking soldering in matlab, training model, cutting pictures on small pices, checking for anomaly 5 diffrent classes. with deep learning (using mutliple layer)
Accuracy: 
CNN: 98.62% 
SVM-CNN: 97.64% 
ResNet: 97.83% 
SVM-ResNet: 98.43%
